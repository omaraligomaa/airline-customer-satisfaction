# Airline Customer Satisfaction Prediction

Machine learning project exploring airline passenger satisfaction using Python, exploratory data analysis, preprocessing, classification, and model evaluation.

**Python · Pandas · Scikit-learn · Machine Learning**

## Project Overview

This project investigates passenger satisfaction using airline service and travel-related features. The analysis and model comparisons are documented in the Jupyter notebook.

## Project Files

- `notebooks/Airline_Customer_Satisfaction.ipynb` — analysis and machine learning notebook
- `data/airplane services.csv` — source dataset

## Workflow

- Exploratory data analysis
- Missing-value handling and preprocessing
- Feature encoding and scaling
- Classification model training and evaluation
- Model comparison

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- Scikit-learn
